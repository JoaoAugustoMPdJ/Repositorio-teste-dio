# Checklist de evidências

Use este checklist para organizar os prints reais antes de subir o repositório no GitHub.

## Prints obrigatórios

- [ ] `01-billing-export-menu.png` — Tela de Billing export no Console GCP.
- [ ] `02-criacao-dataset-bigquery.png` — Dataset `billing_export` criado no BigQuery.
- [ ] `03-configuracao-standard-export.png` — Standard usage cost configurado.
- [ ] `04-configuracao-detailed-export.png` — Detailed usage cost configurado.

## Antes de publicar no GitHub

- [ ] Ocultar ID completo da conta de faturamento, se necessário.
- [ ] Ocultar e-mails, nomes de usuários e dados pessoais.
- [ ] Ocultar valores sensíveis, se o projeto for público.
- [ ] Confirmar que não há chaves, tokens ou credenciais nos arquivos.
- [ ] Confirmar que o README explica o processo e as decisões técnicas.
- [ ] Confirmar que os prints são do ambiente real, não apenas modelos.
