# Checklist de Configuração do Orçamento GCP

Use este checklist para validar se o orçamento e os alertas foram configurados corretamente.

## Acesso e permissões

- [ ] Acesso ao Console da GCP realizado.
- [ ] Conta de faturamento correta selecionada.
- [ ] Permissão suficiente para criar orçamento ou orçamento de projeto.
- [ ] Projeto correto selecionado, caso o orçamento seja por projeto.

## Escopo

- [ ] Orçamento aplicado ao projeto correto.
- [ ] Serviços incluídos revisados.
- [ ] Período definido como mensal.
- [ ] Créditos/descontos revisados conforme necessidade.

## Valor

- [ ] Valor do orçamento definido.
- [ ] Valor compatível com o objetivo do laboratório.
- [ ] Valor abaixo do limite máximo aceitável de gasto.

## Alertas

- [ ] Alerta em 50% configurado.
- [ ] Alerta em 75% configurado.
- [ ] Alerta em 90% configurado.
- [ ] Alerta em 100% configurado.
- [ ] Alerta por previsão de gasto avaliado/configurado.

## Notificações

- [ ] Notificação para administradores de faturamento habilitada.
- [ ] Notificação para responsáveis pelo projeto avaliada.
- [ ] Canal adicional do Cloud Monitoring avaliado, se necessário.

## Evidências

- [ ] Print do painel de faturamento salvo.
- [ ] Print da criação do orçamento salvo.
- [ ] Print dos limites de alerta salvo.
- [ ] Print do orçamento ativo salvo.
- [ ] Print do relatório de custos salvo.
- [ ] Informações sensíveis ocultadas antes de publicar.
