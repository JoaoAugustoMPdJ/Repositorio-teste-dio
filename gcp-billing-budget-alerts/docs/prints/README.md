# Prints de Evidência

Esta pasta deve armazenar os prints reais da configuração do orçamento e dos alertas no painel de faturamento da GCP.

Os arquivos incluídos inicialmente são modelos visuais para orientar quais telas devem ser registradas.

## Prints sugeridos

1. `01-painel-faturamento.png`  
   Tela do painel de faturamento ou menu de Billing.

2. `02-criacao-orcamento.png`  
   Tela de criação do orçamento com nome, escopo e período.

3. `03-limites-alerta.png`  
   Tela com os percentuais de alerta configurados.

4. `04-resumo-orcamento.png`  
   Tela mostrando o orçamento criado e ativo.

5. `05-relatorio-custos.png`  
   Relatório de custos vinculado ao orçamento.

## Atenção

Antes de publicar no GitHub, oculte informações sensíveis, como:

- conta de faturamento;
- dados de pagamento;
- e-mails privados;
- nomes de clientes;
- valores confidenciais.
